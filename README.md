# OpenGL 机械臂 — 第三阶段：手动抓取与搬运

按照 `一.docx` 完成三维场景、键盘操作，以及方块检测、抓取、跟随、释放。保留已确认的**小臂扫动平面垂直于大臂扫动平面**。沿用 C++20、OpenGL 固定管线、GLU、freeglut，无新增图形库或物理引擎，原规划文档未修改。

## 运行

打开 `First.slnx`，选择 **x64 / Debug 或 Release**，生成后 `Ctrl+F5` 运行。也可直接运行：

```text
.\x64\Release\First.exe
```

桌面有红、绿、蓝三个方块。黄色轮廓及 `READY` 表示当前夹爪可夹取，`HOLDING` 表示已抓住，`Released` 表示已释放。界面文字使用 freeglut 支持的英文位图字体。

## 操作

先让机械臂窗口获得焦点，按住运动键连续移动，松开停止。大小写通用，不同关节可同时操作，同一关节反向键抵消。

| 按键 | 功能 | 普通速度与范围 |
| --- | --- | --- |
| A / D | 底座旋转，角度增加/减少 | 60°/秒，[0°,360°) |
| W / S | 大臂抬起/放下，水平为零 | 45°/秒，[-90°,90°] |
| ↑ / ↓ | 小臂正/反方向转动，平面与大臂垂直 | 45°/秒，[-90°,90°] |
| Q / E | 腕部绕小臂轴线旋转 | 90°/秒，[0°,360°) |
| F / G | 闭合抓取 / 张开释放 | 开合比例每秒变化 1 |
| **空格** | 切换 NORMAL / FINE 微调 | 关节为普通速度的 1/50，夹爪为 1/10 |
| Home | 先在当前位置松开携带物，再复位机械臂 | 不重置其他方块或相机 |
| End | 重置机械臂和三个方块 | 重新练习，不改变相机 |
| R | 仅恢复默认相机视角 | 不改变机械臂或方块 |
| 鼠标左键拖动 | 环绕观察 | 不改变物体状态 |
| Esc / 关闭窗口 | 退出 | — |

### 大臂零位调整

旧阶段以竖直向上为大臂 0°，配合垂直肘轴及 ±90° 限位，夹爪无法够到桌面。按确认方案，第三阶段改为**水平向外为大臂 0°**，仍保留 180° 行程。

初始肩角从旧读数 -35° 改为 **55°**，实际渲染使用 `shoulderAngle - 90°`，因此初始外观保持原样。其他初值仍为底座 0°、小臂 -65°、腕部 90°、夹爪全开。小臂角是相对大臂的角度，不是末端世界高度，↑ 不保证任何姿态下末端都单调升高。

## 第一次手动抓取红方块

1. 按 **End** 重置场景，保持夹爪全开。
2. 用 **↑** 将小臂调到 **0°**，用 **E** 将腕部从 90° 调到 **0°**。
3. 底座保持 **0°**，用 **S** 将大臂从 55° 降到约 **-10.62°**。
4. 接近目标时按**空格**切到 FINE，参考实时角度微调。小臂和底座尤其需要接近零位；夹爪必须居中，不能只靠近方块就吸附。
5. 红方块出现黄色轮廓，状态为 `READY cube #1` 后，按住 **F**。接触时开合值停在约 **73%**，显示 `HOLDING cube #1`；不需要、也不能将夹爪强行压到 0%。
6. 按 **W** 抬起方块，再按 A/D 改变底座角度，或用其他关节搬运。腕部旋转时方块朝向也会跟随。
7. 在桌面上方按 **G**，张开到释放间隙后方块解除附着，竖直落到桌面。继续开到足够宽，才方便下一次抓取。

绿、蓝方块的初始抓取目标分别对应底座 **-22°（等价 338°）和 +22°**，大臂仍约 -10.62°、小臂 0°、腕部 0°；它们的朝向已与对应夹持方向匹配。

角度值是操作参考，不是自动定位指令。`READY` 才是实际几何检测结果；搬运后的方块位置、朝向变化，需要重新对准。一次只能携带一个方块。

## 检测、附着与释放规则

- 方块边长 0.22，夹爪最大净开口 0.30。检测在夹持垫中心坐标系内进行；抓取接触开合值不能超过 90%，为之后松开保留余量。
- 抓取需要双侧接触：夹持轴近似对准方块一对相反面、方块居中、两面与夹持垫有足够实际接触面积，并且闭合过程跨过接触间隙。
- 使用真实方块面多边形裁剪及接触深度带，不以中心距离或包围盒重叠直接判定成功。允许合理的方块表面超出窄夹持垫，不模拟任意棱角摩擦夹持。
- 静止的闭合夹爪不能仅靠移动到附近就抓住方块；必须先张开、对准，再闭合。下落中的方块暂不允许接取。
- 抓住时保存 `inverse(夹持世界变换) × 方块世界变换`，不改变方块当时的位置或朝向。随后通过 `夹持世界变换 × 相对变换` 完整跟随。
- 抓住后不能继续夹穿物体。G 打开到有释放间隙时，保存当帧世界姿态再解除附着，不跳回初始位置。
- 释放后仅做竖直重力，保持朝向，不继承机械臂抛出速度。落桌使用旋转后的竖直包围尺寸；投影与桌面重叠则由桌面支撑，完全离开桌面落到地面。低于桌面的方块不会突然向上吸到桌面；若手动把携带物压到地面以下，释放后的下一模拟步会将其恢复到地面下界，避免无限下落。

### 有意保留的简化

没有完整刚体物理、碰撞响应、方块堆叠、弹跳、桌边倾覆、机械臂自碰撞或避障，也没有自动抓取、逆运动学或脚本搬运。方块可能互相重叠；手动将携带物压入桌面等不合理姿态不会自动阻止。桌边有部分投影重叠仍可支撑，不模拟重心倾覆。

## 时间与焦点

- freeglut 约每 16ms 请求更新；以实际经过时间计算，单个 UI 时间片最多 50ms，卡顿时宁可减慢，避免恢复时突跳。
- 每个时间片再分为不超过 1/120 秒的小步检查接触；渲染只读取状态。
- 失焦/最小化会暂停整个模拟并清空运动按键，保留已抓住的方块，回来需重新按键；不会自动松爪。鼠标仅移出窗口不会暂停。
- 微调只改变关节/夹爪输入速度，不减慢重力。清空按键和复位保留当前速度模式。

## 构建环境

本机 Visual Studio 2026、v145、Windows SDK 10、C++20。仅配置并验证 **x64**，Win32 保留原样。

```text
L:\OpenGL\freeglut\include\GL\freeglut.h
L:\OpenGL\freeglut\lib\freeglut_staticd.lib  Debug /MDd
L:\OpenGL\freeglut\lib\freeglut_static.lib   Release /MD
```

`FreeglutRoot` 默认为 `L:\OpenGL\freeglut`，可通过属性表或 MSBuild `-p:FreeglutRoot="新目录"` 覆盖。freeglut 静态链接不需要它的 DLL，但 CRT 仍为动态运行库。

PowerShell：

```powershell
& 'T:\AppSystemFiles\Visual_Studio\MSBuild\Current\Bin\MSBuild.exe' .\First.slnx -m -p:Configuration=Debug -p:Platform=x64
& 'T:\AppSystemFiles\Visual_Studio\MSBuild\Current\Bin\MSBuild.exe' .\First.slnx -m -p:Configuration=Release -p:Platform=x64
.\x64\Release\First.exe
```

